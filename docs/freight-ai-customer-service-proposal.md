## 一、背景与痛点

货代企业客户群多、咨询量大、单证种类繁杂，人工客服普遍面临：

| 痛点 | 现状 |
|---|---|
| **咨询量大** | 单个企业动辄上千个客户群，客服人力跟不上，回复慢、易漏 |
| **单证索取频繁** | 转单号、面单(LB)、发票、POD、DGD、提单等 20+ 类文件反复被索取 |
| **业务术语专业** | 渠道名、单号、报关、计重等专有名词多，新人上手慢、易答错 |
| **7×24 响应难** | 客户随时提问，人工无法全天候在线 |
| **信息散落** | 同一客户多轮咨询，历史信息无法自动串联 |

---

## 二、解决方案

基于自研 **AstraFlow 业务助手引擎**，为货代企业提供**对话式 AI 客服 + 业务助手**，覆盖全部高频客户场景：

```
客户在企微群/客服窗口提问
        │
        ▼
  AI 意图识别（精准判断客户要做什么）
        │
        ├─ 查询类   → 查轨迹 / 查价 / 查偏远 / 查问题件 / 查电话 / 查地址
        ├─ 单证索取 → 转单号 / 面单 / 发票 / POD / DGD / 提单 / 账单 / 报价表...
        ├─ 业务办理 → 代下单 / 改单 / 扣件 / 文件上传 / 收货确认
        └─ 售后    → 投诉 / 转人工 / 任务终止
        │
        ▼
  自动回复 + 自动调取业务系统（订单/运单/财务）
```

**核心能力**：

1. **精准意图识别**：覆盖 30+ 货代业务场景，误判率低；识别理由可回溯，提示词可持续调优
2. **多轮对话收集**：缺什么问什么，如代下单自动收集货物信息、目的地、渠道
3. **行业专有名词识别**：渠道名（如 U009-HKUPS红单5000价）、单号格式等可精准提取与校验
4. **自动标准化**：手机号、日期（今天/明天/下周自动换算）统一格式
5. **多渠道接入**：企业微信群 / 微信客服 / 网页 / App / 公众号
6. **多租户隔离**：多分公司/多客户数据完全隔离
7. **数据安全**：私有化部署可选，数据不出企业内网

## 三、功能清单（覆盖场景）

### 3.1 查询类

| 场景 | 说明 | 示例 |
|---|---|---|
| 轨迹查询 | 按单号查包裹运输状态 | "查下轨迹，这票到哪了" |
| 查价 | 按重量/目的地/渠道查询运费 | "20kg到美国多少钱？" |
| 偏远查询 | 判断地址是否偏远地区 | "这个地址偏远吗？" |
| 问题件查询 | 查询问题件状态 | "这票有问题件吗？" |
| 当地电话查询 | 目的国承运商客服电话 | "美国UPS电话多少？" |
| 收件人地址查询 | 按单号查收件地址 | "收件人地址查一下" |

### 3.2 单证/文件索取类

| 场景 | 说明 |
|---|---|
| 转单号 / 子转单号 | 主单号、分拆子单号索取 |
| 转单标签（LB/面单） | 面单/Label 文件索取 |
| 入仓标签 | 入仓 label 索取 |
| 转单发票 / 客户发票 | 承运商发票、客户提供发票 |
| DGD / DG唛头 | 危险品申报单、危险品唛头 |
| POD 签收单 | 签收证明 |
| 提单 | 头程提单文件 |
| 发票模板 / 报价表 / 客户账单 | 空白模板与账单索取 |
| 单件明细 | 按单号索取单件收货明细数据 |

### 3.3 业务办理类

| 场景 | 说明 |
|---|---|
| 代下单/预报 | 委托下单、预报，自动收集货物信息 |
| 修改订单 | 地址/品名/数量/收件人修改 |
| 扣件 / 取消暂扣 | 暂停发出、取消暂停 |
| 文件上传 | 客户上传发票等资料 |
| 收货确认 | 数据/重量/费用确认 |

### 3.4 售后及其他

| 场景 | 说明 |
|---|---|
| 投诉反馈 | 自动建单转人工 |
| 人工客服 | 一键转接人工 |
| 任务终止 | 取消当前操作 |
| 功能介绍 | 自动介绍可用功能 |

> 场景可按贵司业务**自由扩展**：新增一个场景 = 配置一个注解，无需改框架代码。
